## 🚀 **Conversor de Moedas**
Uma aplicação estática fixa em javascript para treinar a logica e as funções para iniciantes DevClub.

## 🔗 Acesso Online

**[Clique aqui para usar](https://dev-ademir.github.io/ConvdeMoedas/)**

Aplicação web para conversão de valores entre diferentes moedas, desenvolvida como projeto de estudo em JavaScript.

## 🎯 Sobre o Projeto

Conversor de moedas com interface limpa e conversão em tempo real (simulada ou via API). Projeto prático para fixar conceitos de lógica de programação e manipulação de dados.

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3 (design moderno e responsivo)
- JavaScript (ES6+)
- Consumo de API (se aplicável)

## ✨ Funcionalidades

- [x] Conversão entre Real, Dólar e Euro
- [x] Interface intuitiva com seleção de moedas
- [x] Atualização automática de valores
- [x] Design responsivo
